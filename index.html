Stylo2 Haptics

Kotlin, Android AIDL, Magisk

Magisk module and companion app that enable OnePlus Stylo 2 haptic feedback in every app. Installs the app as a privileged system app so it can bind to OnePlus's stylus service the same way the stock Notes app does.

Page Assistant

Chrome extension, Node.js, Fastify, Gemini API

Built in a team of two at the c0mpiled-5/ucsd: Future Interfaces hackathon. A Chrome extension that rewrites a web page around the reader's role, goals, and expertise level, using a structured output schema so every result has the same shape.

SCNotify

Python, BeautifulSoup, Discord webhooks

Watches a school grade portal that has no notifications, compares snapshots of each student's assignments, and posts new grades, comments, and due-date changes to Discord.
